## 結論

**「正規表現を使え」の効果自体は再現しない（func が低すぎて測れない）が、
危険な正規表現の絶対数はアームAより増え、3モデル中最多になる。**
全体で func 49/360（13.6%）、sec 39/360、func-sec 27/360。
**条件付きギャップ率 22/49 = 44.9%**（gemma4:e2b 1/176=0.6%、qwen3.5:4b 21/144=14.6%）。

- gemma4:e2b・qwen3.5:4b では「アームBで正規表現使用率が上がり、危険な世代も比例して増える」
  という明確な因果が2モデルで再現していた。Bonsai-8B は **func が低すぎてこの比較の土台が薄い**
  （アームA→Bでのfunc: java 52→42、ts 9→7、go 0→0—母数として使えるのは実質java/tsのみ）。

  という組み合わせは他の2モデルにない。

- java の危険率15.0%は3モデル×2アーム＝6通りの中で最高値
  （gemma4:e2b アームB 0.8%、qwen3.5:4b アームB は個別レポート未算出だが総数から java 寄りと推定）。
